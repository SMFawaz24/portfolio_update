Chase Tracker

Win probability after every ball of an IPL chase. An XGBoost model trained on 122,857 chase deliveries across all IPL seasons scores a Brier of 0.174 on 16,166 deliveries from 2025 and 2026 that it never saw, against 0.248 for a constant guess. Replay any match, jump to its turning points, or type in a scenario.

Built with Python, XGBoost, FastAPI, JavaScript

Open Chase Tracker

SRM Auto Login

Campus Wi-Fi logs you out every day. This Chrome extension notices the portal redirect, fills in your login and signs you back in. Credentials stay on your device through the Chrome Storage API. About 2,000 students use it.

Built with JavaScript, Chrome Manifest V3, Webpack

Open in Chrome Web Store

Veriflow

Upload a messy CSV and get it back validated, cleaned and transformed. It profiles every column on upload, encodes categories, and gives you an expiring download link. It grew out of my Java Data Scaler engine.

Built with Node.js, Express, REST API

Try Veriflow

ATP Analytics
